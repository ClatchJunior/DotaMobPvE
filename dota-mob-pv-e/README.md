# DotaMobPvE

Проект Godot 4.7 с рендерером Mobile. В первой резервной копии сохранены настройки проекта, иконка и параметры ее импорта. На момент этой копии стартовая сцена еще не задана.

## Как открыть проект

В менеджере проектов Godot выберите «Импорт» и укажите `project.godot` из этой папки. При первом открытии редактор создаст каталог `.godot/` и импортирует иконку.

## Первая резервная копия

Тег `backup-001` отмечает исходное состояние. Для восстановления из резервного файла выполните команду в папке, где находится `DotaMobPvE-backup-001.bundle`.

```sh
git clone --branch main DotaMobPvE-backup-001.bundle DotaMobPvE-backup-001
```

Файл для импорта будет в `DotaMobPvE-backup-001/dota-mob-pv-e/project.godot`.
